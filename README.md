## 🚀 Featured Projects

<details>
<summary><b>🔹 Banking Payment Ledger API — Dual Microservice System</b></summary>
<br/>

A production-style banking ledger system built as a Maven multi-module Spring Boot project, focused on transactional integrity across distributed services.

| Aspect | Details |
|:--|:--|
| **Stack** | Java, Spring Boot, MySQL, JPA/Hibernate, Docker, Jenkins |
| **Architecture** | Dual microservices — `account-service` and `transaction-service` |
| **Reliability** | JWT authentication, compensating transaction rollback (Saga pattern) for distributed consistency |
| **DevOps** | Dockerized services with a Jenkins CI pipeline |
| **Impact** | Deep dive into distributed transaction handling, a core challenge in real banking/fintech systems |

</details>

<details>
<summary><b>🔹 Real-Time Fraud Detection and Alert System</b></summary>
<br/>

An event-driven fraud detection pipeline that flags suspicious transaction patterns in real time.

| Aspect | Details |
|:--|:--|
| **Stack** | Java, Spring Boot, Kafka, Redis |
| **Core Logic** | Redis-based velocity tracking to detect abnormal transaction frequency/patterns |
| **Reliability** | Idempotent Kafka consumers to safely handle retries and duplicate events |
| **Impact** | Hands-on experience with event streaming and real-time decisioning under load |

</details>
